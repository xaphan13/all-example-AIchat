# LLM Council

![llmcouncil](header.jpg)

Идея этого репозитория в том, что вместо вопроса к вашему любимому LLM-провайдеру (например, OpenAI GPT 5.1, Google Gemini 3.0 Pro, Anthropic Claude Sonnet 4.5, xAI Grok 4 и т.д.) вы можете объединить их в свой «LLM Council». Этот репозиторий — простое локальное веб-приложение, которое выглядит как ChatGPT, но использует OpenRouter для отправки вашего запроса нескольким LLM, затем просит их проверить и ранжировать работу друг друга, и, наконец, LLM-Председатель формирует финальный ответ.

Более подробно, вот что происходит при отправке запроса:

1. **Stage 1: Первые мнения**. Запрос пользователя отправляется всем LLM по отдельности, ответы собираются. Индивидуальные ответы показываются в «таб-представлении», чтобы пользователь мог просмотреть их один за другим.
2. **Stage 2: Рецензирование**. Каждому LLM передаются ответы других LLM. Под капотом идентичности LLM анонимизируются, чтобы модель не могла играть в фаворитов при оценке. LLM просят ранжировать их по точности и инсайтивности.
3. **Stage 3: Финальный ответ**. Назначенный Председатель LLM Council берёт все ответы моделей и компилирует из них единый финальный ответ, который представляется пользователю.

## Настройка

### 1. Установка зависимостей

Проект использует [uv](https://docs.astral.sh/uv/) для управления проектом.

**Бэкенд:**
```bash
uv sync
```

**Фронтенд:**
```bash
cd frontend
npm install
cd ..
```

### 2. Настройка API-ключа

Создайте файл `.env` в корне проекта:

```bash
OPENROUTER_API_KEY=sk-or-v1-...
```

Получите API-ключ на [openrouter.ai](https://openrouter.ai/). Обязательно пополните баланс на нужную сумму или настройте автопополнение.

### 3. Настройка моделей (опционально)

Отредактируйте `backend/config.py` для кастомизации совета:

```python
COUNCIL_MODELS = [
    "openai/gpt-5.1",
    "google/gemini-3-pro-preview",
    "anthropic/claude-sonnet-4.5",
    "x-ai/grok-4",
]

CHAIRMAN_MODEL = "google/gemini-3-pro-preview"
```

## Запуск приложения

**Вариант 1: Использовать стартовый скрипт**
```bash
./start.sh
```

**Вариант 2: Запуск вручную**

Терминал 1 (Бэкенд):
```bash
uv run python -m backend.main
```

Терминал 2 (Фронтенд):
```bash
cd frontend
npm run dev
```

Затем откройте http://localhost:5173 в браузере.
