## Ключевые правила

- Управление зависимостями — **только `uv`** (`uv sync`, `uv run ...`). Никогда `pip`/`poetry`.
- **TDD**: сначала тест, затем реализация.
- Работай в feature-ветках: `gh issue develop <НОМЕР_ЗАДАЧИ>`.
- Вноси минимальные изменения; не рефактори «по пути» без необходимости.
- Комментарии и докстринги — на русском (следуй стилю репозитория).
- Перед завершением обязательно прогоняй:
  `uv run ruff check` + `uv run ty check` + `uv run pytest -m "not live"`.

## Специфика Claude Code в этом репозитории

- `.claude/settings.local.json` описывает разрешения (Bash, Search, Edit, Read, Write …)
  и **Stop-hook** `.claude/hooks/lint-and-typecheck.sh`.
- Stop-hook запускает `uv run ruff check` и `uv run ty check` после каждой итерации и
  **блокирует завершение** при ошибках (exit 2), чтобы ты их исправил. Не обходи и не
  отключай этот hook без явной необходимости.
- Полный список важных нюансов (гонки, мёртвый код, catch-all границы и т.д.) —
  в разделе «Важные нюансы» `AGENTS.md`.
