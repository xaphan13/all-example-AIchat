# CLAUDE.md

Руководство для Claude Code. Файл `AGENTS.md` — канонический универсальный файл для всех харнессов: если читать только один файл, читай его.

> English version: [CLAUDE.md](CLAUDE.md) · Универсальный файл: [AGENTS.ru.md](AGENTS.ru.md)

## Перед началом — прочитай документацию

Папка `docs/` — авторитетная документация проекта. Прочитай соответствующий документ, вместо того чтобы обходить весь репозиторий:

1. `AGENTS.ru.md` — обзор проекта, конвенции, команды (~2 мин)
2. `docs/01_project_structure.md` — карта модулей
3. `docs/02_architecture.md` — архитектура, паттерны, потоки данных
4. `docs/03_execution_flow.md` — процессы в рантайме, обработка ошибок, graceful degradation
5. `docs/04_code_quality.md` — оценка качества, технический долг
6. `docs/05_optimization_roadmap.md` — запланированные рефакторинги и оптимизации

Только после этого открывай код в `app/`, `frontend/` или `tests/`.

## Особенности Claude Code

- Будь консервативен: минимальные точечные правки, соответствующие существующему стилю и конвенциям из `.cursor/rules/project-development.mdc` (без хардкода данных, логика на LLM).
- Проверяй изменения: `pytest tests/ -v`.
- Не выполняй git-мутации (`commit`, `push`, `reset`, `rebase`) без явного подтверждения пользователя.
