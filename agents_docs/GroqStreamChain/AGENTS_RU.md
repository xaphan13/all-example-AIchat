# Инструкции для AI-агентов — GroqStreamChain

## Обзор проекта

**GroqStreamChain** — это приложение чата в реальном времени с потоковой передачей ответов, построенное на FastAPI, WebSocket и Groq LLM. Предоставляет современный веб-интерфейс для общения с ИИ с потоковой выдачей ответов.

- **Язык**: Python 3.12+
- **Фреймворк**: FastAPI + WebSocket
- **LLM**: Groq (через API, совместимый с OpenAI)
- **Фронтенд**: Vanilla JS + шаблоны Jinja2
- **Менеджер пакетов**: uv (pyproject.toml)

## Структура репозитория

```
GroqStreamChain/
├── server.py          # FastAPI приложение, WebSocket-эндпоинт
├── config.py          # Конфигурация (HOST, PORT, API-ключи)
├── system_prompts.py  # Шаблоны системных промптов
├── pyproject.toml     # Зависимости и метаданные проекта
├── requirements.txt   # Устаревшие требования для pip
├── models/
│   └── chat.py        # Модели данных ChatSession, Message
├── services/
│   └── llm_service.py # Интеграция с LLM (потоковая передача Groq)
├── static/            # Фронтенд-ресурсы (CSS, JS)
├── templates/
│   └── index.html     # Основной шаблон страницы
└── docs/              # Документация проекта (см. ниже)
```

## Ключевые технические детали

### Зависимости
- FastAPI, Uvicorn (ASGI-сервер)
- Groq SDK (поставщик LLM)
- OpenAI SDK (Groq совместим с OpenAI)
- Jinja2 (шаблонизатор)
- WebSockets

### Конфигурация
- Вся конфигурация в `config.py`: HOST, PORT, GROQ_API_KEY
- Поддержка `.env` файла через стандартные паттерны Python

### Запуск проекта
```bash
# С помощью uv (рекомендуется)
uv sync
uv run python -m server

# Или напрямую
python server.py
```

### API-эндпоинты
- `GET /` — Веб-интерфейс
- `WS /ws/chat` — WebSocket-эндпоинт для чата
- `GET /health` — Проверка состояния

## Соглашения о кодировании

1. **Типизация** — Используйте аннотации типов во всём Python-коде
2. **Логирование** — Используйте модуль `logging`, а не `print`
3. **Async/await** — Предпочитайте асинхронность для I/O операций
4. **Обработка ошибок** — Грациозная обработка ошибок, сервер никогда не должен падать
5. **Именование** — snake_case для функций/переменных, PascalCase для классов
6. **Импорты** — Группировка: стандартная библиотека → сторонние → локальные
